# Integration contract

Set `AGENT_FACTORY=your_package.agent:create_agent` and `POLICY_FACTORY=your_package.policy:create_policy`; both are zero-argument factories. Each request gets fresh instances. Return an asynchronous `step(prompt, remaining_usd)` implementation and `evaluate(PolicyContext)` implementation respectively. Bundle the package in the image. Configuration comes from operators, never request parameters. See `c4l/contracts.py` for typed contracts.

Adapter responsibilities: preserve continuation state across steps; validate model/tool allowlists and destination URLs; prevent SSRF; reserve worst-case provider cost before dispatch; cap input/output tokens and all tool calls; report aggregate Decimal USD including retries; use provider deadlines shorter than the request deadline; propagate cancellation; avoid background calls. Hidden loops invalidate the governance boundary. Break existing agents at model/tool invocation boundaries so the graph can govern each billable or consequential operation. Side-effecting tools require explicit authorization, idempotency keys and their own policy check before execution; they are disabled by design until implemented.

Policy phases: input before any agent execution, before_step before every bounded action, output before candidate release or continuation. Decisions are allow, stop or review, each with a stable reason code and version. Unknown or failed policy evaluations fail closed. `review` withholds output and requires a separate authenticated human workflow; no resume endpoint exists yet. Add identity, resource, tool proposal and trusted evidence fields to the contract before authorizing real tools. Do not infer identity from prompt text.

The baseline policy only demonstrates length, secret-pattern and injection checks. These are incomplete heuristics and do not establish safety. The supplied paper now defines ARDC as Adaptive Recursive Dimensional Compression. See ARDC_PAPER_REVIEW.md and c4l/ardc.py for the paper-derived reference controller; live proxy calibration and application-specific policy rules remain unapproved. Policy owner must supply decision tables, escalation contacts, versioning and adversarial acceptance cases.

Hard envelope: 3 steps, 15 seconds, USD 0.02 per request, 4 concurrent agent requests per process. Bounds are operator-owned constants. The cost check can withhold an over-budget result but cannot reverse provider spend; pre-dispatch reservation must be enforced by the adapter. Timeout cancellation cannot guarantee that a remote provider stopped billing. Errors/timeouts increment unknown usage; reconcile with provider records. Per-process concurrency is not a global quota. Live use requires an atomic shared tenant/day budget and provider quota, conservative reservation, settlement, and recovery after worker failure. AWS Budgets sends delayed alerts, not hard spending caps.

No automatic retries, persistent conversation memory, prompt/output logging, or agent network access are provided by the demo. OTEL spans contain node names only. Configure exporter authentication and private transport when enabling telemetry. Do not enable LangGraph state streaming/debug tracing with sensitive prompts.

## Trusted measurements and numeric audit

`StepResult.measurement` optionally carries a `DepthMeasurement` for the executed depth. `MeasuredARDCPolicy` requires it. Use a request-scoped zero-argument factory to construct the measured policy with an explicit ControllerConfig and approved guardrails. Protocol IDs must bind evaluator revision, data/window, metrics, baseline and proxy definitions; a string alone does not prove provenance. Measurement code must be trusted instrumentation outside user/model control. Graph state accumulates numeric audit rows without exposing them through the public response. Wire a durable approved audit sink before live deployment. No measured-demo factory is automatically enabled.
